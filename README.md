\# Duplicate File Finder (C# / .NET)



Консольний застосунок для високопродуктивного пошуку файлів-дублікатів за їхнім вмістом у вказаній директорії та її підпапках.



Основою реалізації є алгоритмічна оптимізація: назва файлу та його розширення ігноруються, а порівняння вмісту відбувається за трирівневою системою фільтрації.



\---



\## 💡 Алгоритм та складнасть ($O$-нотація)



Пряме порівняння кожного файла з кожним ($O(N^2 \\cdot K)$) є неефективним для великих обсягів даних. У цьому проєкті застосовано \*\*трирівневий алгоритм мінімізації дискового I/O\*\*:



1\. \*\*Групування за розміром ($O(N)$):\*\*

&#x20;  - Усі файли скануються рекурсивно та групуються за їхнім розміром у байтах.

&#x20;  - Унікальні за розміром файли одразу відсіюються без зчитування їхнього вмісту.



2\. \*\*Часткове хешування / Перевірка сигнатури:\*\*

&#x20;  - Для файлів з однаковим розміром зчитуються лише перші кілька кілобайт (наприклад, 4 KB) для обчислення первинного хешу.

&#x20;  - Це дозволяє швидко розрізнити великі файли з однаковим розміром, але різним початковим контентом.



3\. \*\*Повний хеш (MD5 / SHA256) ($O(M \\cdot K)$):\*\*

&#x20;  - Повний хеш обчислюється \*\*виключно\*\* для потенційних кандидатів, які пройшли перші два етапи.



> \*\*Підсумкова складність:\*\* 

> - \*\*Часова складність:\*\* $O(N + M \\cdot K)$, де $N$ — загальна кількість файлів, $M$ — кількість потенційних дублікатів ($M \\ll N$), $K$ — середній розмір файла.

> - \*\*Просторова складність:\*\* $O(N)$ для збереження метаданих файлів у пам'яті.

\## 🛠 Технологічний стек



\- \*\*Мова:\*\* C# (.NET 8 / .NET 9)

\- \*\*Архітектура:\*\* Clean Architecture / SOLID (розподіл на `Core`, `ConsoleApp`, `Tests`)

\- \*\*Тестування:\*\* xUnit

\- \*\*Конкурентність:\*\* `Task Parallel Library (TPL)` / `Parallel.ForEach` для паралельної обробки файлів.
